# GA4 Ecommerce Analytics

Work in progress: e-commerce funnel and retention analysis using Google Analytics 4 sample data and BigQuery SQL.

## Data source
Google's public `ga4_obfuscated_sample_ecommerce` dataset:
https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset

## Scope
- Event coverage and data-quality checks
- Sequential session conversion funnel
- User cohort and retention analysis

## Limitations
The sample data is obfuscated and may have limited internal consistency.
No causal effects or A/B test results are claimed.
